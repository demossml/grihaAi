# Remont Report (быстрый путь)

## Цель
Отдавать развёрнутый PDF-отчёт группы «ремонт» мгновенно, без повторного
разбора чеков и лишних токенов.

## Быстрый путь (обязательный)
1. НЕ читай историю чата и НЕ парси позиции заново — данные уже лежат в БД
   (`~/.grish-ai/finance.sqlite`, таблица `expenses`, chat_id `-5400215325`,
   позиции — в `line_items` / `items_json` таблицы `expense_documents`).
2. Запусти готовый генератор:
   `node_modules/.bin/tsx scripts/gen-remont-expanded.mjs`
   Он читает БД, собирает эталонную форму и пишет PDF в `~/.grish-ai/reports/`.
3. Отправь сгенерированный PDF через `send_file` (kind=document, caption —
   только «Отчёт по расходам — группа «ремонт»»). Без лишнего текста.

## Эталонная форма (жёстко)
- заголовок «Отчёт по расходам — группа «ремонт»»
- каждый чек отдельно: дата + поставщик
- внутри чека — ВСЕ наименования позиций с суммами
- итог по каждому чеку
- разбивка по назначению: закупка материала / услуги / закупка оборудования
  (с подсуммами)
- общий ИТОГО за период

## Период
- «за весь период» = все данные (без дат).
- Явный диапазон — только если пользователь назвал период.

## Правила
- Итог = сумма из БД, никогда не выдумывать.
- Только PDF-файл, без сопроводительного текста (report_attachment_only).
- Если в БД нет розничных позиций (line_items пусто) — не выдумывай
  наименования, верни только имеющиеся чеки/суммы и предупреди одной строкой.
