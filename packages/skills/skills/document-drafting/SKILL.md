# Document Drafting

Draft short documents (letters, memos, notes).

## Workflow
1. Confirm the purpose, recipient and tone.
2. Draft the document with the LLM.
3. Return the draft for review; do not send outside without approval.

## Rules
- Do not mix drafts with fixed report templates (`generate_report` /
  `generate_presentation`) — those have fixed layouts.
- Sending a draft outside requires a connector + approval.
